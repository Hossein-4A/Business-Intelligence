# Business Intelligence Projects

A collection of Business Intelligence and data analysis projects focused on transforming structured data into useful insights and management dashboards.

## Projects

### 1. Data Analysis of Rail Passenger Companies
Analysis of passenger and travel data with Microsoft Excel and Power BI. The project includes data preparation, statistical analysis, dashboard development, and supporting project documentation.

**Tools:** Microsoft Excel · Power BI · Statistical Analysis

### 2. Remote Monitoring of Patients
A Business Intelligence project focused on organizing remote patient monitoring data and presenting key information through interactive Power BI dashboards.

**Tools:** Microsoft Excel · Power BI · Data Visualization

## Skills Demonstrated

- Data cleaning and preparation
- Exploratory and statistical analysis
- Business Intelligence and dashboard design
- Data visualization
- Management reporting
- Translating data into actionable insights

## Repository Structure

- `Data analysis of rail passenger companies/` — source data, Power BI dashboard, reports, and presentation materials
- `Remote monitoring of patients/` — source data, Power BI dashboard, and project report
